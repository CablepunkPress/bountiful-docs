# bountiful-docs

The documentation for Bountiful.

- `bountiful_docs/guide/` is the user guide. It explains how to install Bountiful, make agents, and use them.
- `bountiful_docs/technical/` is the technical guide. It explains how each part of Bountiful works.
- `bountiful_docs/tool_groups/docs/` holds the docs tools, which every Bountiful agent uses to read these docs.
- `decisions/` records decisions about Bountiful's design.
